Introducción a HTML

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Describe la estructura de una página web utilizando elementos que le dicen al navegador cómo mostrar el contenido.

Esta página es un ejemplo básico de cómo estructurar contenido usando HTML semántico y estilos CSS internos.

[Imagen ilustrativa sobre HTML]

Características Principales

  • Estructura clara: Uso de elementos semánticos
  • Diseño responsive: Se adapta a diferentes dispositivos
  • Código limpio: Fácil de entender y modificar
  • Estilos integrados: CSS dentro del mismo documento

Ejemplo de Código

Aquí hay un ejemplo básico de código HTML:

<!DOCTYPE html>
<html>
<head>
  <title>Ejemplo</title>
</head>
<body>
  <h1>Hola Mundo</h1>
</body>
</html>
